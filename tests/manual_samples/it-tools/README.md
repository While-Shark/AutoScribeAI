## 검증 상태

세 가지 워크플로는 모두 ‘미검증’ 상태입니다. 대상 앱을 실행하거나 스크린샷을 수집하지 않았으며 품질 보고서는 `ready: false`입니다.

절차는 공개 소스 코드에서 정리한 후보입니다. 실행 중인 IT Tools 화면에서 검증하지 않았습니다.

소스 목록: [`inventory.json`](inventory.json); 생성 설정: [`project.json`](project.json); 실행 기록: [`run/manifest.json`](run/manifest.json).
